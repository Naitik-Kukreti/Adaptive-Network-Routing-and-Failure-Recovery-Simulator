1. Project Abstract & Core Research Objectives (Report Page 2)

          

          

            Modern computing systems rely fundamentally on distributed networks for data communication. However, real-world communication links and routing appliances are prone to runtime failures midway or dynamic congestion. Such failures cause packets to be delayed, discarded, or severed from reaching their final destinations.
          

          
          

            

              01
              
Network Modeling

              
Object-oriented abstraction of routers, links, packets, buffers, and dynamic graph topologies.

            

            

              02
              
Algorithmic Routing

              
Implementation and benchmarking of BFS, DFS, and Dijkstra shortest path pathfinding algorithms.

            

            

              03
              
Failure Stimulation

              
Simulating real-world network anomalies via deliberate link severing and router node crashes.

            

            

              04
              
Failure Recovery

              
Autonomous anomaly detection and transparent packet rerouting over healthy bypass links.

            

            

              05
              
Adaptive Recovery

              
Dynamic failover strategy that attempts optimal Dijkstra routing with intelligent fallback to BFS.

            

            

              06
              
Evaluation Metrics

              
Rigorous quantification of packet delivery ratio, loss rate, recovery time, and path cost.

            

          

        


        
        

          

            
            
2. Object-Oriented Design & Architecture

          

          

            The project adheres to high-cohesion, low-coupling C++ OOP principles, now executed directly in both terminal and web layers:
          

          

            

              
 Router Class

              
Encapsulates router ID, descriptive label, active/failed operational state, and a FIFO packet queue (std::queue<Packet*>) handling buffer storage.

            

            

              
 Link Class

              
Models bidirectional communication channels between router pairs, associated with an integer cost/weight and operational state (fail() / repair()).

            

            

              
 Packet Class

              
Represents data transmission units containing unique packet IDs, source, destination, priority level, and an auditable route trail (std::vector<int>).

            

            

              
 Network Class

              
Graph management container maintaining routers list, links list, and adjacency map. Hosts BFS, DFS, and Dijkstra algorithms and connectivity algorithms.

            

            

              
 RoutingStrategy Hierarchy

              
Polymorphic abstract base class featuring derived BFSStrategy, DijkstraStrategy, and AdaptiveStrategy (with automatic failover).

            

            

              
 Simulation Class

              
Coordinates topology orchestration, packet lifecycle, failures, algorithm comparison, telemetry statistics, and file persistence (saveNetworkToFile).
